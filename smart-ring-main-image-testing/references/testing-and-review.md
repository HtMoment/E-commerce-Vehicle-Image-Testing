# 测图与复盘

## 1. 明确实验对象

- **首图测试：** 多个候选均承担首图截停任务，CTR 为主指标；后续图片及商品信息尽量稳定。
- **承接图测试：** 固定首图，比较第二至第五张的内容或顺序；使用实际可获得的浏览、加购、成交等指标，不凭首图 CTR 归因。
- **方向探索：** 比较不同卖点、场景和表达的整体组合，只得出组合层面的结论。
- **单变量验证：** 在同一方向中改变一个主要因素，并核对实际图片的非预期变化。

测试范围由用户当前需求决定，不为一次首图优化默认制作和更换整套图片。

## 2. 平台与投放条件

先明确当前平台、展位和可用的实验机制。源材料中的“直通车”和“只投京东”不能混为同一后台；未明确平台时可以提供通用实验设计，不给出伪确定的菜单操作。

涉及具体按钮、图像规格、创意数量、流量机制、推荐入口时，根据当前官方说明或用户实际后台核对。查不到就明确未核实，不引用旧教程证明今天仍适用。

记录并尽量稳定：商品/SKU、价格与促销、关键词及搜索意图、匹配方式、人群、地域、时段、设备、渠道/展位、出价策略、预算约束、落地页/后续图片、创意标题和素材版本。

如平台提供实验分流，优先使用可比较的分配方式。轮播、关闭自动改图和自动偏配有助于减少干扰，但不保证随机分配或完全公平；仍要核对实际曝光与流量组成。曝光数不同本身不必然使测试无效，需结合分流机制与人群差异判断。

分计划、分日期或不同位置测试时，应记录差异并限制因果结论，不能将一切变化归于图片。广泛匹配改为精准匹配、明显改变出价或促销后，另开数据阶段；不同阶段不能直接合并为同一次图片实验。

## 3. 计划输出

给出可执行计划时包含：

1. 本轮问题、目标人群/词、对照版本与候选版本。
2. 探索/单变量模式、固定项与变化项。
3. 已确认平台能力、分流方式及尚未核实事项。
4. 用户允许的预算、预计观察窗口、成本边界和样本规划依据。
5. 需收集字段、预先设定的评估时点和结束条件。
6. 保留、重测或迭代的判断方法。

预算、出价、周期和批次数量需结合当前输入确定。缺少预算时可以给待填写的计划，不虚构用户接受的花费。按预定样本或时间评估，避免每天挑一个暂时领先者就宣布胜出；多版本筛选之后应安排复验。

## 4. 数据字段与计算

最低需要：图片编号/版本、投放时间、曝光、点击、投放条件或阶段标记。复盘可按现有报表增加花费、加购、订单、归因成交额及归因窗口。

| 指标 | 计算与注意事项 |
|---|---|
| CTR | 点击数 / 曝光数；显示百分比，零曝光为无法计算 |
| CPC | 花费 / 点击数；零点击为无法计算 |
| 点击转化率 | 按相同报表口径，用归因订单或买家数 / 对应点击口径；分母不一致时不混用 |
| 广告投入产出比 | 同一归因口径的成交额 / 花费；零花费无法计算，不等同于净利润 |
| CTR 绝对差 | 候选 CTR − 对照 CTR，以百分点表示 |
| CTR 相对提升 | 候选 CTR / 对照 CTR − 1；对照 CTR 为零时不报告相对提升 |

同时保留原始曝光、点击与时间范围。仅有点击数不能算 CTR；仅有 CTR 而无样本量不能判断稳定性。若报表给 UV、PV、重复点击或去重指标，先确认统计口径，不擅自互换。

统计独立性、随机分流、样本量或多重比较条件不足时，不把简单显著性计算当成因果证明。如做置信区间/检验，说明方法、假设与限制；样本量取决于基础 CTR、最小关注差异、置信水平和检验效能，不存在通用“若干点击即有效”的门槛。

首图以 CTR 为主指标。加购、成交和成本用来排查吸引不相关点击、承接不一致及商业不可用等问题，观察时需考虑转化延迟；不能把无成交的小样本自动判为失败。

## 5. 结论与下一轮

按证据选择表述，不强迫每轮选出赢家：

- **信息不足：** 补曝光、时间、版本或口径；能计算的先算，不能补造数据。
- **条件不可比：** 指出人群、匹配、时段、促销或位置变化；分段展示，重新设计比较。
- **候选领先：** 当前 CTR 较高，但样本或条件不足以确认优势；延长观察或复验。
- **支持在当前条件下优先使用：** 可比性和样本支持实际有意义的差异，检查承接与成本后，在同类条件中继续验证。
- **暂未发现明确差异：** 不把“没有证据证明不同”写成“两张一样好”；根据成本与业务需要决定迭代。

给出具体动作，例如继续收集相同条件数据、只调整主标题、改用同一底图重新验证背景，或对领先整体方案做单变量细化。替换店铺首图或迁移到其他流量位置时，属于新的应用场景，需要继续观察，不能仅凭付费 CTR 高于自然 CTR 直接认定应替换。

复盘记录保留：素材与版本、测试假设、数据期间、投放条件/变化、原始数值、计算结果、局限、结论和下轮动作。没有后台提供的单图浏览数据时，不编造第二至第五张的单独留客或转化贡献。

## 6. 用户原始资料中的经验与处理方式

以下是本方法整理时收到的资料，不是平台现行规范；后续用户明确的任务约束优先。

| 资料中的内容 | 本 Skill 的使用方式 |
|---|---|
| 早期文本：4 张轮播、保留前 2 张 | 作为批次示例，不设固定数量或强制赢家数 |
| XMind：每次 3 张创意图 | 同样作为批次示例，依据流量和预算安排 |
| 早期文本：单图 15—20 点击、通常 3—5 天 | 可作初步观察经验，不能判定稳定胜出 |
| XMind：单图 50 点击以上、至少 3 天、最佳 7 天 | 记录为较充分观察的经验窗口，不保证统计可靠性 |
| 早期文本：手动出价如 0.3 | 示例价格，不作为默认出价 |
| XMind：预算 100 元、建议出价的 70% | 案例参数；未明确预算周期，不能擅自写成每日预算 |
| XMind：相关词全选、广泛后改精准 | 不作为固定必经操作；词意图应匹配，匹配方式改变后分段复盘 |
| XMind：只投京东、全时段 100%、地域全开 | 平台特定案例，实际范围按当前投放目标确定 |
| 轮播、关智能创意 | 检查当前后台是否支持，限制自动变体，核对实际分流；不声称确保公平 |
| XMind：“竞品的图放上去” | 用于研究竞品表达，以自己的产品素材制作测试版本；确有授权素材时按授权范围使用 |
| 推广 CTR 高于免费 CTR 就替换主图 | 两种流量可能不可比；列为候选，在目标使用位置验证 |
| 首图是给系统看的、非白底就丢推荐 | 保留重视 CTR、准备白底素材的意图，不保留未经核实的流量保证 |

统计方法参考：[NIST 比例样本量说明](https://itl.nist.gov/div898/handbook/prc/section2/prc242.htm)、[NIST 两比例比较](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/diffprop.htm)。前者说明样本量受基础比例和目标差异等因素影响，不提供广告平台专用阈值。

历史平台材料参考：[阿里妈妈 2015 年点击率优化文章](https://www.alimama.com/news_detail.htm?contentId=2360)。其“四创意”等内容不能作为当前后台数量限制的依据。
