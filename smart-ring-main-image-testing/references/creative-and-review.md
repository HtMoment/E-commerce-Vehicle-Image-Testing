# 创意与审核

## 1. 从产品卖点到用户买点

以用户的真实购买原因组织信息，参数和功能用于支撑。优先分析评论、问大家、客服记录和产品资料；未提供这些材料时提出待验证假设，不虚构用户反馈。

| 挖掘维度 | 检查问题 |
|---|---|
| 使用前/生产前 | 用户原本有什么不便或顾虑？原料与前期工艺是否有可证实的价值？ |
| 使用中/生产中 | 产品如何被佩戴、使用？哪些操作或制造细节能直观呈现？ |
| 使用后/生产后 | 用户获得什么信息、便利或体验？哪些差异有事实支撑？ |
| 使用者 | 谁佩戴，重视什么体验，在哪些条件下使用？ |
| 购买者 | 谁支付，为什么购买，需要什么决策依据？ |
| 受益者 | 谁获得价值，是否与使用者、购买者不同？ |
| 注意力与拉新 | 哪个真实特点可以引发好奇，能否快速看懂是什么产品？ |
| 促销与决策 | 当前真实活动、权益或服务能否解决购买顾虑？ |
| 场景 | 哪个具体时刻最能表达这个买点？ |
| 差异与表达 | 与目标展位的竞品相比，有什么值得测试的角度、文案或画面差异？ |

以上是可组合的创意元素，不要求凑足十个或全部塞进一张图。每个方案选择一个主买点，配必要的场景与证据即可。营销可考虑拉新、加购及成交阶段，但不得编造折扣、销量或限时条件。

买点记录建议包含：用户原话及来源、需求/顾虑、产品事实及来源、文案方向、视觉表达、待验证假设。

示例仅用于说明表达方式：若真实产品支持睡眠记录，可测试“昨晚睡得怎样”这一问题式切入点，用辅助信息解释记录能力。不能因此宣称“戴上睡得更好”。若有重量依据，可测试“具体重量”与“日常佩戴利益”两种表达，不预设参数文案一定差。

## 2. 五张主图的职责

| 位置 | 角色与任务 | 画面选择 | 审核关键 |
|---|---|---|---|
| 第一张 | 视觉锤：截停，首要测试指标为 CTR | 戒指特写、鲜明轮廓、佩戴反差、动势构图、简洁强对比或极致美感 | 一个焦点、一项主信息；能识别商品，不堆全部功能 |
| 第二张 | 痛点解药：回答“好在哪、与我有什么关系” | 一个真实需求与一个对应能力，用直观情境呈现 | 痛点、功能与用户利益之间关系清楚，不给无关细节 |
| 第三张 | 信任锚点：回答“凭什么相信” | 真实材质、细节、工艺、对应检测或功能依据 | 每条证据支撑明确主张；报告适用于该型号与该主张 |
| 第四张 | 使用向往：帮助想象拥有后的体验 | 真实适用的工作、休息、穿搭或运动佩戴场景 | 代入感与产品辨识兼顾；不暗示未经证实的效果或使用条件 |
| 第五张 | 设计版：解决尚未回答的购买问题 | 根据需求选择尺寸、适配、使用方式、服务等 | 不预设必须放白底；避免重复前四张 |
| 备用素材 | 清晰白底产品图 | 干净背景、完整产品、准确材质、饱满构图 | 作为备用或按当前展位要求使用，不承诺推荐流量 |

这一顺序用于组织内容，不假设每位用户都按顺序看完。单张应能独立表达核心信息。需要整套制作时，先明确第五张的任务；资料不足可提出有依据的候选方向，不编造规格或服务。

首图的冲突、悬念和美感是创意手段。竞品普遍用全景时可以测试特写，竞品静态时可以测试动势；差异是否有价值要由实际竞品对照和投放结果验证。首图 CTR 是主指标，后续加购、成交和成本用于判断承接与商业可用性，不能以吸引误解换取点击。

## 3. 方案卡与提示词

每版用稳定编号标识位置和版本，例如 H1-A-v1。记录方向探索或单变量验证，后续编辑保留版本关系。

方案卡按需要填写：

- 图片位置与任务、目标人群/关键词。
- 假设、主买点、产品依据。
- 主标题、副文案及准确文字。
- 主体、背景/场景、光影、构图、字体与信息层级。
- 平台/展位、比例、实际像素、裁切与留白要求。
- 固定项、变化项、产品还原约束。
- 待确认事项、预期检验方式。

提示词结构：

> 人群与搜索意图 + 本轮测试假设 + 已确认卖点 + 产品主体 + 场景背景 + 光影风格 + 构图视角 + 画质与交付尺寸 + 文案排版 + 还原约束。

可填充模板：

```text
依据提供的产品参考图，为［型号/颜色］AI 智能戒指制作［位置、比例、实际像素］主图。
面向［人群/搜索意图］，本图任务是［首图截停/痛点回应/信任证据/使用体验/决策信息］。
只表达［已确认的一个买点］，依据为［产品资料/真实素材］。
主体呈现［视角、位置、展示区域］，保留［实际材质、外观及结构］。
背景/场景为［描述］，搭配物为［描述及主次］。
使用［方向与软硬程度］的光线，形成［真实反光与质感］；景深、色调为［描述］。
主标题准确写为“［文案］”，副文案为“［文案或无］”；在［位置］排版，统一［对齐、字体、间距］，强调［重点］。
产品与文字在目标展位的缩略图尺寸下清晰，关键结构不被文字遮挡。
保持戒指厚度、内圈、传感器、标识及佩戴比例与参考一致。
不新增未提供的结构、功能、配件、数据、认证或 App 界面。
本轮固定［项目］，仅改变［变量］。
```

生成前补全可确认项，删除不适用项；需要保留的未知项明确标注，不能把含未知事实的模板称为最终可投放素材。产品缺少某视角的参考时，不承诺该视角下隐藏结构准确。

“4K”“商业摄影”是风格/质量意图，实际输出像素、裁切、锐度与文字准确性另行核验。必要时先生成无字底图，再排准确中文；最终审核包含文字层。

## 4. 控制版本变化

仅修改提示词一个词不能保证生成结果只变化一个因素。单变量版本优先从同一底图局部编辑，或使用相同产品图与排版模板修改目标元素。

逐项检查主体大小、角度、位置、光线、背景、文字和搭配物是否发生非预期变化。无法保持其他要素稳定时，将该组标为整体创意对比，不声称某一个要素产生了效果。

单变量改图指令示例：

```text
基于当前已审核底图，仅将背景由［A］调整为［B］。
保持戒指形状、材质、位置、大小、光线、阴影、文案与排版一致。
如为实现背景变化必须连带调整阴影，明确记录这一变化，复查后决定是否仍可作为单变量比较。
```

## 5. 投放前审核

| 检查项 | 达标口径 |
|---|---|
| 主题 | 一个主买点，表达明确，紧扣消费者诉求 |
| 文案 | 主标题尽量 6 字以内；大白话、准确、能感知；副文案补解释或依据，不增添平行主主题 |
| 层级与对齐 | 文字默认统一居左或居右，必要的特殊构图说明理由；字号/颜色用于重点区分 |
| 视觉顺序 | 阅读路径清楚；可从左到右、从上到下，或从中心焦点到两侧，不机械强加多条相冲突路径 |
| 统一与重心 | 字体、颜色、样式、间距一致；图文比例平衡，画面重心稳定 |
| 主体与搭配 | 产品主导画面；产品特写以展示区域约占三分之二为优先目标；佩戴图保持真实比例，用裁切突出戒指 |
| 产品完整性 | 不用大量文字覆盖主体，内圈或关键细节不被错误重绘；搭配物不暗示虚假的套装内容 |
| 证据 | 功能、参数、效果、活动、报告、界面与对应产品资料相符 |
| 同屏模拟 | 与实际相关展位的竞品比较拍摄、排版、文案差异；无竞品时标为待验证 |
| 缩略图 | 按目标展示大小检查，争取第一秒吸引、下一秒读懂；这是审核目标，不是实测结果 |
| 交付质量 | 实际像素/比例符合已确认要求，中文正确，无手指或佩戴畸变，无错误配件、标识与结构 |
| 测试可解释性 | 固定项/变化项与实际画面一致，多变量变化已标明 |

审核结论：

- **通过：** 已检查项目满足进入测试的条件，并列出仍需投放验证的假设。
- **需修改：** 指明图片编号、具体区域、问题及可执行修改动作。
- **信息不足：** 说明缺少的参考图、依据、竞品或展位信息；继续完成能独立判断的项目。

不以主观分数或“高级感”代替具体问题，不声称审图能预测真实 CTR。不凭空给出“必爆”“必推量”或“非白底必丢推荐”等结论。
